# 🚀 Meli + Ada: Lógica de Programación en Java

Repositorio con el desarrollo de clases, retos y examen final del módulo de Lógica de Programación en **MercadoLibre & Ada (2026)**.

## 📂 Estructura del Repositorio
* **clase1_helloworld/**: Primeros pasos e impresión en consola.
* **clase2_operadores/**: Uso de operadores aritméticos y conversor de monedas.
* **clase3_scanner/**: Lectura de datos por consola y formateo de texto (`FichaAlumno`).
* **clase4_funciones/**: Modularización de código y reutilización con funciones.
* **clase5_condicionales/**: Estructuras de decisión (`if-else`) y uso de `Enum`.
* **clase6_bucles/**: Ciclos repetitivos (`do-while`) y lógica de juegos interactivos.
* **clase7_matrices_vectores/**: Manipulación de arreglos unidimensionales y matrices bidimensionales.
* **clase8_excepciones/**: Control de errores con bloques `try-catch` y excepciones personalizadas.
* **examenjava_jhonatan_osorio/**: Evaluación final.
